# Скилл «Карта гипотез»

Скилл помогает ИИ-агенту создавать, фасилитировать, проверять и обновлять Карты
гипотез по действующему стандарту 1.2. При подключённом MCP агент может работать
с проектами непосредственно в Социотехе.

## Возможности

- построение новой карты набегающими волнами;
- проверка целей, метрик, субъектов, мотивации, гипотез, задач и связей;
- субъектные и прямые контуры гипотез;
- обычная ЭКГ и ЭКГ по красному пути;
- выбор подходящей топологии;
- особенности личной стратегии;
- чтение и изменение существующего проекта через MCP Социотеха;
- проверка записанного результата и поиск логических разрывов.

Скилл помогает удерживать нотацию, но не заменяет владельца карты, предметных
экспертов и сертифицированного фасилитатора.

## Установка

Скопируйте папку
[`skills/hypothesis-mapping`](../skills/hypothesis-mapping) целиком в каталог
пользовательских скиллов вашего ИИ-агента. Не загружайте один `SKILL.md`
отдельно: для работы нужны файлы из `references/`.

Конкретный путь установки зависит от клиента. Имя папки должно остаться
`hypothesis-mapping`, чтобы совпадать с полем `name` в `SKILL.md`.

Для работы с проектами Социотеха подключите в своём MCP-клиенте адрес:

```text
https://mcp.sociotech.center/mcp
```

Авторизацию выполняйте в интерфейсе MCP-клиента. Не передавайте токены и пароли
ИИ-агенту в сообщениях. Согласно странице подключения, MCP доступен на тарифе
Социотеха «Профи».

Без MCP скилл продолжит работать в режиме фасилитации и сможет подготовить
структурированный черновик, но не будет утверждать, что результат сохранён в
Социотехе.

## Состав

```text
skills/hypothesis-mapping/
├── SKILL.md
└── references/
    ├── examples.md
    ├── facilitation.md
    ├── sociotech-mcp.md
    ├── standard-1.2.md
    └── topologies.md
```

`SKILL.md` содержит рабочий процесс и правила выбора справочников. Подробный
стандарт, фасилитационные приёмы, топологии, MCP-процесс и примеры загружаются
только по необходимости.

## Примеры запросов

### Создать новую карту в Социотехе

> Изучи материалы проекта о запуске корпоративного питания в новом городе.
> Создай Карту гипотез в Социотехе. Не добавляй неподтверждённые выводы как
> факты; неизвестные значения оформи блокерами. После записи проверь все связи.

### Проверить существующую карту

> Прочитай Карту гипотез в проекте «Новый рынок». Проверь цели, метрики,
> субъектов, формат гипотез и трассировку задач до целей. Ничего не изменяй,
> только перечисли проблемы и предложи варианты исправления.

### Изменить одну ветку

> В проекте «Удержание сотрудников» обнови только ветку специалистов первого
> года работы по итогам приложенных интервью. Сохрани остальные ветки без
> изменений и перечитай карту после записи.

### Провести ЭКГ по красному пути

> Помоги провести ЭКГ по красному пути для цели роста выручки. Задавай по одному
> вопросу, не придумывай метрики и не переходи к задачам до формулировки
> гипотезы.

### Построить личную стратегию

> Помоги построить личную стратегию. Верхний уровень сделай с субъективными
> метриками, нижний — с объективными. Не сохраняй чувствительные детали, которые
> не нужны для карты.

## Обновление скилла

При выходе новой версии стандарта сначала обновите
`references/standard-1.2.md`, затем проверьте `SKILL.md`, остальные справочники и
[eval-сценарии](../tests/hypothesis-mapping-evals.md) на изменившуюся
терминологию, поля, цвета и связи.
