# Топологии Карты гипотез

Справочник основан на публичном каталоге топологий:
https://github.com/Byndyusoft/hypothesismapping/blob/main/topology.md

Топологии можно комбинировать. Сохранять стандартные цвета элементов.

| Топология | Когда использовать | Что учитывать |
|---|---|---|
| Классическая | Первый проход, обучение, простая карта | Универсальна, но в реальной сессии часто быстро требует усложнения |
| Многоуровневая | Задача верхней карты сама требует стратегии, например строительство завода | Верхняя карта служит основанием для нижней; сохранять трассировку между уровнями |
| Метрики цели на отдельном уровне | Метрик много или нужно показать влияние на конкретную метрику | Видны метрики без влияний, сила влияния и расхождение важности с покрытием |
| Иерархия целей | Цель достигается этапами или раскладывается на несколько горизонтов | Допустимо любое число уровней и ветвлений |
| Многоцелевая карта | Несколько целей используют общих субъектов или гипотезы | Сложнее одновременно приоритизировать элементы относительно разных целей |
| Мотивация на отдельном уровне | У субъекта несколько неоднородных болей и желаний | Связывать каждую гипотезу с конкретной частью мотивации |
| Разбивка задач по направлениям | Нужно показать отделы, исполнителей, канбан или перейти к дорожной карте | Не менять цвет задач ради обозначения исполнителя; использовать группы или метки |
| Доска задач / портфель проектов | Нужно отслеживать статусы реализации | Задачи остаются горизонтально связаны с гипотезами; сложнее перейти к многоуровневой карте |
| Теги или ярлыки вместо стрелок | Большое количество стрелок ухудшает читаемость | Связь становится менее наглядной; использовать только при сохранении однозначной трассировки |
| Группировка элементов | На несколько элементов действует одно и то же влияние | Сохранять возможность отдельной связи с элементом внутри группы |

## Правила выбора

- Много метрик → вынести метрики на уровень.
- Несколько целей с общими ветками → использовать многоцелевую карту.
- Цели на разных горизонтах → использовать иерархию целей.
- Масштабная задача → создать нижележащую карту.
- Неоднородная мотивация → вынести мотивацию на уровень.
- Много связей → сначала попробовать группировку, затем теги или ярлыки.
- Нужны ответственность и статусы → использовать группировку задач или доску.

Не менять топологию только ради визуального разнообразия. Выбирать её, если она
делает причинные связи и белые пятна заметнее.
