# Скиллы ИИ-агента для работы с картами Социотеха
Социотех позволяет работает со всеми функциями через ИИ-агента, подключенного к MCP-серверу. Инструкция для подключения: https://sociotech.center/mcp

Для того, чтобы ИИ-агент не отклонялся от стандартов [Связанного SWOT-анализа](https://linkedswot.com/), [Карты гипотез](https://картагипотез.рф/), [Карты процесса-опыта](https://ashapiro.ru/xpm) и [Карты реализации историй](https://ashapiro.ru/articles/sim), ему нужно дать правильные навыки, в рамках которых он точно не ошибется.

В этом проекте собраны скиллы для ИИ-агента под каждый инструмент Социотеха.
