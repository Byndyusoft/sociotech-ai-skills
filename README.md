# Скиллы ИИ-агента для инструментов Социотеха

В репозитории собраны самостоятельные скиллы, которые помогают ИИ-агентам
соблюдать нотацию инструментов Социотеха и безопасно работать с проектами через
MCP.

Инструкция по подключению Социотеха: https://sociotech.center/mcp

## Готовые скиллы

| Инструмент | Скилл | Документация | Проверки |
|---|---|---|---|
| Связанный SWOT-анализ | [`linked-swot`](skills/linked-swot) | [Описание](docs/linked-swot.md) | [Eval-сценарии](tests/linked-swot-evals.md) |
| Карта гипотез | [`karta-gipotez`](skills/karta-gipotez) | [Описание](docs/karta-gipotez.md) | [Eval-сценарии](tests/karta-gipotez-evals.md) |

Машиночитаемый список опубликован в [`catalog.json`](catalog.json).

## Планируемые инструменты

- [Карта процесса-опыта](https://ashapiro.ru/xpm)
- [Карта реализации историй](https://ashapiro.ru/articles/sim)

Для нового инструмента добавляется отдельная самодостаточная папка в `skills/`,
документация в `docs/`, сценарии проверки в `tests/` и запись в каталоге.
Подробности — в [CONTRIBUTING.md](CONTRIBUTING.md).

## Установка

1. Выберите нужный каталог в `skills/`.
2. Скопируйте его целиком в пользовательский каталог скиллов вашего ИИ-агента,
   сохранив имя конечной папки.
3. При необходимости подключите MCP Социотеха.

Каждый скилл самодостаточен: его `SKILL.md` ссылается только на файлы внутри
собственной папки.

## Структура репозитория

```text
.
├── catalog.json
├── CONTRIBUTING.md
├── skills/
│   ├── karta-gipotez/
│   │   ├── SKILL.md
│   │   └── references/
│   └── linked-swot/
│       ├── SKILL.md
│       └── references/
├── docs/
├── tests/
└── scripts/
```

## Проверка

Перед публикацией выполните:

```bash
python3 scripts/validate_repository.py
```

Проверка контролирует каталог, имена папок, фронтматтер, локальные ссылки,
самодостаточность и обязательные файлы.
