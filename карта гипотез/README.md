# Карта гипотез — скилл для Claude

Фасилитатор для построения стратегии по методу **«Карта гипотез» Александра
Бындю**. Ведёт по шагам от цели к задачам, задаёт правильные вопросы и
помогает не совершить типовые ошибки — так, как это делал бы опытный
проводник по методу.

## На чём основан

Метод «Карта гипотез» Александра Бындю — книга «Карта гипотез. Как создать
стратегию для себя, своей семьи и бизнеса» («Автор», 2025) и открытый
репозиторий [Byndyusoft/hypothesismapping](https://github.com/Byndyusoft/hypothesismapping).

Скилл переносит логику метода в формат, который Claude применяет прямо в
диалоге: движение справа налево (цель → субъект → гипотеза → задача), работа
с самодвижением субъекта и переводом его с естественной траектории на
управляемую, связки «если — то — потому что» с опорой на мотивацию субъекта.

## Как работает

Запускается по смыслу задачи — когда описываешь цель, идею или проблему, к
которой не знаешь как подступиться («помоги построить стратегию», «есть идея,
не знаю с чего начать»). Дальше Claude ведёт тебя по шагам построения карты,
поясняет каждый шаг и не даёт проскочить середину — из цели сразу в задачи,
минуя субъектов и гипотезы.

Результат — не просто нарисованная карта, а пройденный тобой путь
рассуждения.

## На что обращать внимание

Скилл — это проводник, а не автопилот. Два ограничения, которые важно
держать в голове:

**Про метод.** Карту гипотез нельзя «получить» — её нужно прожить. Скилл
задаёт структуру и вопросы, но думаешь и решаешь ты. Если переложить само
размышление на ИИ, на выходе будет красивая, но пустая карта — форма без
твоего понимания.

**Про инструмент.** Скилл работает поверх ИИ, а ИИ может отклониться от
заложенной логики, что-то упростить или увести в сторону. Держи руль:
сверяй происходящее с самим методом, а не полагайся, что рамки соблюдаются
автоматически.

## Что внутри

Скилл — это папка из трёх файлов:

- **SKILL.md** — ядро навыка: инструкции фасилитатора и метаданные (имя,
  триггеры запуска). Именно этот файл Claude загружает и исполняет. Лёгкий
  вход — с него начинается работа.
- **reference.md** — справочник: шаблоны каждого элемента карты (цель,
  субъект, гипотеза, задача, метрики) и каталог типовых ошибок с алгоритмами
  исправления. Фасилитатор сверяется с ним по ходу нужной фазы.
- **examples.md** — разборы и примеры из книги: ими фасилитатор иллюстрирует
  шаг, ошибку или приём, не отсылая к первоисточнику.

Такое разделение — штатный для Claude приём «прогрессивного раскрытия»:
лёгкий SKILL.md загружается сразу, а тяжёлые материалы (справочник, примеры)
подтягиваются только когда нужны.

## Установка

Для работы скилла нужны **все три файла** — `SKILL.md`, `reference.md` и
`examples.md`. `SKILL.md` — точка входа, но он ссылается на два других файла,
поэтому по отдельности скилл работать не будет.

Порядок такой:

1. Скачайте по очереди все три файла (на GitHub откройте файл и нажмите
   кнопку скачивания в правом верхнем углу).
2. Положите их в одну папку у себя на компьютере.
3. Загрузите папку в Claude: веб-версия (claude.ai) → Настройки →
   Возможности/Навыки → добавить свой навык.

После установки навык запускается сам, когда задача подходит под его
триггеры (описание цели, «помоги построить стратегию», «не знаю, с чего
начать» и т. п.).

> Точный путь пунктов меню может отличаться в разных версиях интерфейса.
